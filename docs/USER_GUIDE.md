# User guide

1. Start Streamlit and leave **Demo (no API key)** selected.
2. Upload a CSV/XLSX file or click **Load fictional sample**.
3. Review warnings, exclusions, and the cleaned preview in **Upload & validation**.
4. Explore governed metrics in **Dashboard**.
5. Select an approved brief and generate a narrative in **AI insights**.
6. Ask aggregate analytical questions in **Ask the analyst**.
7. Download Markdown, PDF, cleaned CSV, or KPI CSV from **Export**.

If required columns are absent, correct the source using `data/templates/upload_template.csv`. Never use the included fictional data as if it represented a real institution.
